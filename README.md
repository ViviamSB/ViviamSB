# Viviam Bermúdez

Computational researcher with a background in molecular and cell biology, working at the intersection of data analysis, mechanistic modelling, and AI-supported research. Experienced in developing Python-based tools and reproducible workflows for complex data, with strengths in model evaluation, technical problem-solving, and interdisciplinary collaboration.

## Selected projects

- **SYNCO** — https://github.com/ViviamSB/SYNCO  
  Python package developed to integrate model predictions with experimental drug-response data, evaluate performance using ROC/PR curves and classification metrics, and support interactive visualisation.

- **TRAFIKK** — https://github.com/druglogics/trafikk  
  End-to-end computational pipeline for predicting and interpreting anticancer drug synergies. Contributed to the Python modules **Celios**, **Drexpa**, **SYNCO**, and **Siflex**.
